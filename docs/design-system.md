# 🎨 CFIT Design System

> Versão 1.0

---

# Objetivo

O Design System do CFIT define os padrões visuais e de experiência do sistema.

Todo componente novo deve seguir este documento.

---

# Princípios

- Simples
- Moderno
- Consistente
- Rápido
- Profissional
- Responsivo
- Reutilizável

---

# Inspirações

- Next Fit
- Linear
- Stripe
- Notion
- Vercel

# Layout

Sidebar fixa.

Topbar fixa.

Conteúdo ocupa toda a área restante.

Sempre utilizar bastante espaço em branco.
