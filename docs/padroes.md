# Padrões de Desenvolvimento do CFIT

## Idioma

Todo o código será escrito em inglês.

Comentários e documentação serão escritos em português.

## Nomenclatura

Classes:
- PascalCase

Exemplo:
- Aluno
- Matricula
- Pagamento

Funções:
- snake_case

Exemplo:
- criar_aluno()
- calcular_vencimento()

Variáveis:
- snake_case

Exemplo:
- data_vencimento
- valor_plano

Arquivos Python:
- snake_case

Exemplo:
- aluno.py
- pagamento.py

Pastas:
- snake_case

Exemplo:
- usuarios
- financeiro

## Organização

Uma responsabilidade por arquivo.

Uma classe por arquivo (sempre que possível).

Não duplicar código.

Priorizar legibilidade em vez de escrever menos linhas.

## Git

Todo recurso novo deve ser desenvolvido em uma branch própria.

Commits devem possuir mensagens claras.

Nunca fazer commit de arquivos temporários.
